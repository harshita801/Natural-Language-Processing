# 🧠 Natural Language Processing (NLP) Fundamentals

Welcome to my hands-on NLP repository! This project serves as a comprehensive, step-by-step guide to mastering the fundamentals of **Natural Language Processing (NLP)** using **Python** and **NLTK**. It tracks my journey from basic text preprocessing to advanced vectorization techniques and future LLM applications.

---

## 📚 Topics Covered

### 🔹 Text Preprocessing & Linguistics
*   **Tokenization:** Splitting text into sentences and words.
*   **Stemming:** Reducing words to their base/root form using heuristic rules.
*   **Lemmatization:** Vocabulary and morphological analysis to return dictionary base forms.
*   **Stopword Removal:** Filtering out common, low-information words.
*   **Part-of-Speech (POS) Tagging:** Identifying the grammatical categories of words.
*   **Named Entity Recognition (NER):** Extracting and classifying entities (Names, Places, Orgs).

### 🔹 Text Vectorization & Feature Engineering
*   **Bag of Words (BoW):** Counting word frequencies to build document vectors.
*   **TF-IDF (Term Frequency-Inverse Document Frequency):** Scaling word importance based on document uniqueness.
